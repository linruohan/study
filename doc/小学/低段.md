# 小学低段语文（约 6–8 岁）

这是语文材料。小学的全部学习见 [目录.md](目录.md)，不以识字作为唯一内容。

目标：把已经认识的字放进句子，并按学校识字量补充新字。材料是课文选句、儿童诗和生活短文，不代替统编课文，也不规定必须来自某一本蒙书。

一年级约三百字、二年级约五百字、三年级累计约一千六百字，仍是学校的标尺。本目录只覆盖其中一部分，缺口用课文补，不靠加长古文来硬补。

- 一年级：具体名词和短句。一天一句，深挖两个字。
- 二年级：稍长的叙述句，仍是现代汉语。可以听一个古人怎样把字刻在器物上的故事，故事标清传说或考古，不绑定某一篇韵文。
- 三年级：一段话。德行若出现，用今天校园和家里做得到的事来讲，例如把话说完、承认改错，不抽象讨论哲学。
- 每学期诵读大约十到十五则短材料，求听过、跟读、能背其中一部分。
- 字形固定三格：古形、繁体、简体。繁体只认，不默写。三格用一次字形渐变串起来。
- 书写若家长打开，只写简体，而且只写课标已经要求会写的字。笔顺可选，不占主路径。

生僻字只在跟读时出现，标成「听见即可」。

已写好的识字衔接仍然有效：幼儿字库里的「日、月、山、水、人、手、衣」进入短句，例如「太阳出来了」「我穿衣服」。古形到简体的渐变从这些字开始做。
