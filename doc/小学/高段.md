# 小学高段语文（约 9–11 岁）

这是语文材料。同龄的数学、科学、其他学科见 [目录.md](目录.md)，内容不从这篇语文里派生。

目标：能讲清一段材料在说什么，能在地图或时间上找到位置，开始使用完整演变链。

材料三份，分开存放在学习列表里，不合成一本韵文：

1. **地图与家乡。** 中国地图、省级行政区的常见简称、地形和气候的常识、一次家乡调查。地图使用合规标准底图，不自行拼接边界。历史地名若出现，并列今名。
2. **时间与人物。** 一条简单时间线，人物故事每次只放一个名字。故事标「传说」「文献」或「考古」。不把神话讲成已证实的历史。
3. **短诗和短文。** 每学期十五到二十则是上限。先成诵，再讲意思。七言诗和很短的文言只占其中一部分，其余用现代说明文。质量高于覆盖。

幼儿或低段已经认识的「山、水、河、海、田、日、月」，在地图和节气材料里再次出现，不当作新字。

字形演变在这一档可以看全链。六书只作为分析工具：象形、指事、会意可以看图；形声讲形旁和声旁，并说明声旁在今天常常已经不准确。

若要写，只做「用今天的话讲这一则」，八十到一百五十字，可选。写作不在产品里批改。

经典原文不在本目录展开。想读《诗经》或《论语》的一句，到中学目录去，而且每次只读与本课直接相关的一句。
