# 小学 6–8 岁

这一档的学习都从看得见、数得清、做得了的事情开始。语文怎样读句子，用 [低段.md](低段.md)。下面是其他学科在这一档要覆盖的内容。

| 学科 | 这一档学什么 | 不在这一档做的事 |
| --- | --- | --- |
| 数学 | 20 以内加减，表内乘除的起步，认识钟表和人民币，厘米和米，长方形、正方形、圆 | 不讲方程、分数运算和圆周率推导 |
| 英语 | 字母，课堂问候，颜色、数字、动物和家庭的听说 | 不写短文，不讲语法术语 |
| 科学 | 观察并记录：种子发芽、天气、物体沉浮、磁铁能吸什么 | 不写完整实验报告，不讲分子 |
| 道德与法治 | 家庭称呼和分担家务，上课听讲，说真话，过马路走斑马线，自己的物品自己收 | 不讲抽象的权利条款 |
| 艺术 | 跟唱短歌，涂色和剪贴，分辨高低和强弱 | 不要求临摹完整作品 |
| 体育与健康 | 走跑跳、拍球、排队、课间喝水，出汗后休息 | 不测专项竞技成绩 |
| 劳动 | 洗手、整理书包、擦桌子、帮忙摆碗筷 | 不使用刀和热油 |
| 信息 | 知道设备有开关，用完让眼睛休息，不把家里的事告诉屏幕对面的人 | 不登录账号，不编程 |

数学用实物和画图。科学一次只观察一个现象，记录用图画加几个字。英语以听和跟读为主。
