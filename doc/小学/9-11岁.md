# 小学 9–11 岁

这一档开始读得懂一段说明，算得清一类图形，做得完一次简单实验。语文用 [高段.md](高段.md)。下面这些内容不从低龄识字表里生成。

| 学科 | 这一档学什么 | 和 6–8 岁的差别 |
| --- | --- | --- |
| 数学 | 大数，运算律，小数和分数，多边形面积，比例，圆，百分数，用图解释鸡兔同笼、植树问题 | 不再以 20 以内口算为每日主课 |
| 英语 | 听短对话，读配图小段，写几句自己的话，从句子里认识常见时态 | 不再只认单词卡 |
| 科学 | 力怎样改变运动，光和影子，简单电路，生物按特征分类，地球自转和昼夜、月相的观察 | 要写观察了什么、改变了什么、看到了什么 |
| 道德与法治 | 班级规则为什么要大家遵守，社区里的公共设施，遇到欺凌找谁，网络上的话也要负责 | 用校园里的具体事情讨论，不背条文 |
| 艺术 | 合唱里的自己的声部，写生一个静物，听得出曲子的快慢和重复 | 要完成一件能拿给别人看的作业 |
| 体育与健康 | 一种球类的基本规则，耐力跑的呼吸，热身和运动后的拉伸，受伤先停下来 | 开始有规则和安全，不排名羞辱 |
| 劳动 | 浇水种植，洗菜，使用安全的小工具，收拾自己的手工 | 劳动有开始、过程和收尾 |
| 信息 | 用文件夹保存自己的作业，用表格记下一次测量，搜索后看信息从哪来，不转发未经核对的话 | 信息课学的是记录和核对，不是另一门识字 |

地图、家乡和节气放在科学和语文的说明文里各用一次，不单独变成识字课程。标准地图用已审核的底图。
