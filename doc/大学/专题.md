# 大学专题

专题是研究写法，不是大学的全部课程。18–20 岁各学什么，见 [18-20岁.md](18-20岁.md)。

目标：自己把问题、材料、出处和结论写成一个小题目。

每个专题必须留下出处。区分传说、文献和考古。结论允许写成「此处不能确定」。

适合放进本目录的题目举例：

- 一个字的生活义和古书里的用法为什么不同。
- 传说中的造字，和目前能见到的甲骨文，分别能说明什么。
- 古都名称对应今天的哪座城市，哪些宫室名是文学套语。
- 简体里哪些字与繁体同形，哪些是新造或同音替代。

题目不限定在同一本书里。中学目录的短选可以引用，引用时写明篇目，不把那些短选再排成唯一课本。
