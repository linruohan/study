# 社区与公共事务

目标：参与身边可核对的公共事务。从读懂一份公告开始，到组织一次行动为止，每一步都留下能复核的记录。

## 读与问

- 公告栏、业主群、政务通知：先找四样——时间、地点、要做什么、找谁。方法见知识库「群治之学」的「读懂一张通知」。
- 信息公开原则：自己的证件和票据不发群；别人的信息不代发。要传达的话，转公告原文链接，不转转述。
- 有异议走正道：按公告给的联系渠道提意见，意见写事实和建议，不写推测。

## 参与组织

- 参加一次公共议事（业主会、居委会活动），会前准备一页：主张、依据、建议。发言按这一页说。
- 预算与账目：能看懂物业或活动的收支公示，方法见知识库「群治之学」的「给活动做预算」；数字对不上就问，问到对上为止。
- 组织一次行动：分工、时间、收尾负责人写清楚，方法见「组织一次集体行动」。做完把结果告知每个参与者。

## 边界

- 这里只处理身边事务，不延伸到政治立场；公共规则以现行法规和公告原文为准。
- 不传播未经证实的说法，尤其是健康与安全类；核对方法见 [健康与科学.md](健康与科学.md)。
- 答错没有惩罚，笔记要能指出信息从哪来——这条规则与本目录其他材料相同。
