# 公共文本

目标：读懂生活里真会遇到的文字，并知道哪些话需要核对。

材料用公开的、与具体公司无关的示例类型，不收集用户自己的合同、票据或证件：

- 小区和学校通知：时间、地点、要做的事、联系谁。
- 药品和食品说明：用法、用量、保存、警示。看不懂或身体不适，材料停在「去问医生或药师」，不提供用法建议。
- 票据和账单：金额、日期、项目名称分别在哪里。
- 合同的常见栏目名称：当事人、期限、费用、解除。只认栏目，不代替律师解释某一份合同是否有效。

场景是街道、银行网点、医院窗口、单位公告栏。人物遵守普通规则：排队、在指定窗口办事、不把别人的信息公开出来。

动画若使用，仍是短镜头：一个人在公告栏上找到日期，或在说明里找到「用量」两个字。不演纠纷升级，不教规避规则。
