## 二、自动分类总规则

### 2.1 先问功能，再问内容

同一对象在不同功能下面向不同类别。自动分类的判定顺序：

1. **它回答什么核心问题？** 用上表的关键词组匹配。
2. **语境功能是什么？** 教学/传承 → 史；做理论 → 哲；做作品 → 赋；做攻防 → 战；做推算 → 观；做健康 → 医；做系统 → 匠；做治理 → 治；做自我 → 我。
3. **有主归属先归主归属**，次属作为补充标签（数据库子分类的 `question` 字段已注明次属指向）。

### 2.2 冲突消解优先级（从高到低）

当多个类别同时命中时，按以下顺序裁决：

1. **对抗 > 其他**：只要核心是冲突/攻防/竞争（军事、网络安全、竞技、博弈实操），归「战」。
2. **生命 > 制作**：核心是维护健康与生命（临床、护理、公共卫生），归「医」；仅为医疗做器械才归「匠」。
3. **表达 > 制作**：核心是审美与叙事（作品、表演、创意），归「赋」；为实现作品而造系统才归「匠」。
4. **教养 > 群治**：核心是经典与规范的传承（经典研读、教育史），归「史」；核心是现实组织与资源分配，归「治」。
5. **理论 vs 应用二分**：同学科有理论/应用两面的，理论归「哲」、应用归其功能类（多为「治」）。
6. **造物兜底归「匠」，社会组织兜底归「治」，心智兜底归「我」**。

### 2.3 三条排除规则

- **语言不整体归类**：语言按功能面向拆分（见第四节）。
- **交叉学科取主功能**：如生物信息学（工具服务于生命研究 → 医/观，视研究对象），STS（理论面向 → 哲）。
- **应用场景不改变学科主体**：体育教育史仍归「史」，金融科技工程仍归「匠」。

## 四、语言的分层归类（自然语言与计算机语言）

语言**不贴唯一标签**，按功能面向拆分。同一语言（中文、英文、C、Python）可同时出现在多个类别。

## 七、自动分类判定流程（伪代码）

```text
classify(obj):
  if 核心是冲突/攻防/竞争:            return 对抗(战)
  if 核心是维护健康与生命:            return 生命(医)
  if 核心是审美/情感/叙事作品:        return 表达(赋)
  if 核心是造物/系统构建:             return 制作(匠)
  if 核心是自然/时空/数理推算:        return 天地(观)
  if 核心是组织/制度/资源/权力:       return 群治(治)
  if 核心是心智/自我/意义:            return 自知(我)
  if 核心是概念/理论/观念批判:        return 思辨(哲)
  if 核心是经典/规范/文明传承/教育:   return 教养(史)
  if 是语言:                         按第四节功能面向拆分，可多标签
  else:                              兜底教养(史)  # 传统与人文默认
```

> 维护约定：新增子分类先在 `server/db` 新开迁移（021 起），再回填本文档第三/六节；跨类对象一律「主归属落库 + question 注明次属」。
