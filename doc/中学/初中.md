# 初中语文（12–14 岁）

这是语文与文献材料。同龄其他学科见 [12-14岁.md](12-14岁.md)。

目标：从记住单字转到读懂一段，并核对出处。

- 文言短文和古诗按主题选，例如论学、写景、人物一件事。能回答：这段出自哪里，选本里的用法和原始出处有没有差别。
- 演变链在这一档看完整，并认出繁简同形。同音替代留到高中。
- 议论文写法不是这里的功能。产品只提供可核对的材料：原句、出处、史实标签。
- 古代伦理、征伐和刑罚可以讲解，放回成文的时代。不做成可模仿的动作。今天人与人的冲突由法律处理，这句话写在阅读说明里，不演出惩罚。

每天大约二十分钟：读一段，核对一处出处。每周把本周出现的人物放到同一条时间线上复述一次。
