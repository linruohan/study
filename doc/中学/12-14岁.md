# 中学 12–14 岁

语见 [初中.md](初中.md)。这一档把学科分开学。每门课回答的问题不同，材料也不能互相代替。名称以 [../学科.md](../学科.md) 为准。

| 学科 | 这一档学什么 |
| --- | --- |
| 语 | 文献短选、出处和复述 |
| 数 | 有理数，整式与因式分解，一元方程和方程组，一次函数，几何证明的基本格式，数据的平均数和频数 |
| 音乐 | 听完一首短曲，说出它的快慢、重复和自己听到的情绪，不把情绪说成唯一正确答案 |
| 历史 | 中国古代到近代的时间顺序，世界史里的若干关键转折。每次讲清一件事的原因和结果，史料不足就写「材料不够」 |
| 地理 | 地球的运动，气候的主要类型，中国的区域差异，等高线和方向的判读。地图用标准底图 |
| 英语 | 读懂一段叙事或说明，写一个有开头和结尾的段落，在句子里使用常见从句 |
| 生物学 | 细胞的基本结构，人体消化、呼吸和循环在做什么，遗传的初步概念，一个生态系统里的吃与被吃 |
| 物理 | 声、光、力、热、电的现象和测量。先会用单位和刻度，再谈公式 |
| 化学 | 物质由微粒构成，常见的化合与分解，实验时的护目、通风和不尝药品 |
| 法治 | 未成年人保护，权利与义务在校园里的具体例子，宪法是国家的根本法这一层常识。用条文名称和事例，不代替律师 |
| 体育 | 一项运动的规则和基本技术，青春期的身体变化用科学说明，睡眠和饮食 |
| 美术 | 能说出一幅画的题材和自己的感受，临摹服务于观察 |
| 劳动 | 一种家务的完整流程，一种传统工艺的安全入门，例如缝补或种植 |
| 信息 | 用顺序、分支描述一件事，知道账号和验证码不能交给别人，能分辨广告和报道 |

物理、化学、生物都属于科学，实验先写安全，再写步骤。历史和地理各用时间线或地图，不并进语的古文课。
