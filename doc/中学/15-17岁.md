# 中学 15–17 岁

语见 [高中.md](高中.md)。这一档学习原理、模型和证据，题目与初中不同。名称以 [../学科.md](../学科.md) 为准。

| 学科 | 这一档学什么 |
| --- | --- |
| 语 | 两种叙述对照，繁简和句读只在这一科里讲 |
| 数 | 函数的性质，三角，数列，立体几何，概率统计，导数作为变化率的入门。计算要写清条件 |
| 音乐 | 依据一段旋律写几句评论：哪里重复，速度怎样，自己依据哪一句 |
| 历史 | 用两则史料对照同一件事，区分原始记述和后人解释，中外各选一个专题而不是再背一遍通史年表 |
| 地理 | 大气环流和洋流怎样影响气候，人口与城市，一个区域的发展限制。结论要能回到地图 |
| 英语 | 较长语篇的结构和作者态度，口头或书面说明一个观点并给出理由 |
| 物理 | 牛顿定律的适用条件，能量守恒在一个具体过程里的账，电与磁的基本现象，一次实验的误差来源 |
| 化学 | 化学反应的限度和速率在定性层面怎么理解，元素与结构的关系，有机物的典型类别。不配制危险物 |
| 生物学 | 细胞的分子组成在学什么，遗传信息怎样传递的主线，内环境稳态的例子 |
| 法治 | 按课程标准接触经济、法律、政治和哲学里的基本概念。每个概念配一个能核对的公共事例，不把口号当成答案 |
| 体育 | 专项技术的改进，运动损伤的预防，体能练习有计划也有休息日 |
| 美术 | 写一段短评论：作品在做什么，自己依据哪一处画面 |
| 通用技术 | 为一个生活里的小不便写出需求、方案和一样限制条件 |
| 信息技术 | 用表格或简单程序处理一批自己的数据，知道算法是步骤，结果要能复算 |

高中讨论繁简里的同音替代、偏旁类推，放在语文，不占用物理化学的课时。
