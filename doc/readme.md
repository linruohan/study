# 学习阶段总览

| 阶段 | 年级/年段 | 说明 |
| --- | --- | --- |
| 蒙学 | 学前启蒙（约 3-5 岁） | 兴趣培养、感知与习惯养成 |
| 小学 | 一年级至六年级（约 6-11 岁） | 基础读写算与学习习惯建立 |
| 初中 | 初一至初三（约 12-14 岁） | 分科知识体系与思维能力发展 |
| 高中 | 高一至高三（约 15-17 岁） | 学科深化与学业/生涯规划 |
| 大学 | 大一至大四（约 18-21 岁） | 通识与专业教育、综合能力培养 |
| 研究生 | 研一至研三 | 学术研究能力培养路径（总览方案） |
| 硕士 | 硕一至硕三 | 专业实践能力培养路径（总览方案） |
