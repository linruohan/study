# 幼儿的情绪与相处

这一档学习说出自己的感受，并在真实场合里做一个小的选择。不诊断情绪，不给家长打「情商分」。

| 年龄 | 做得到的事 |
| --- | --- |
| 3 岁 | 在脸上指出高兴、生气、难过。语音说「他现在怎么样」 |
| 4 岁 | 等待：轮到自己再拿积木。想要时用手势或短句，而不是抢 |
| 5 岁 | 碰到做不到的事，在图里选出「找爸爸妈妈」或「休息一下」。和别人不一样时，两个人可以各选各的 |

场景是家里、公园和饭桌。带路的人先问孩子看到了什么，再问可以怎么做。答法没有唯一正确的情绪。若孩子点了「难过」，就停在「可以告诉身边的人」，不继续追问原因。

不出现吓唬人的脸，不把哭当成失败。
