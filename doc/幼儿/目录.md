# 幼儿（蒙学）

蒙学计划包含**识文**、**识数**、**识物**三部分，在同一条启蒙路线中展开。

3–5 岁，见 [../readme.md](../readme.md)。这一档给还不会读菜单的孩子用。操作靠触摸和语音。识字、数、情绪和动手放在同一条路线里，不分成学校那种学科首页。

每天约十分钟。家长可以在旁边，孩子也能凭声音和手指自己点下去。不写字，不排行，不用连续打卡惩罚。

| 材料 | 文件 | 在这条路线里做什么 |

| 怎么带着学 | [路线.md](路线.md) | 大按钮、语音、带路的人、一条混合路径 |
| 语 | [识字.md](识字.md) | 看图认字。3 岁、4 岁、5 岁各认一部分 |
| 数 | [数学.md](数学.md) | 数实物、比多少、认形状 |

历史和地理到 6 岁以后才单设。学科全表见 [../学科.md](../学科.md)。
| 千字文 | [千字文](千字文) | 已写好的可选文稿。不进每日路线，也不供给其他年龄当主线 |

新档案从路线的第一步开始：先听一句，再点一块大图。6 岁进入小学后，改用文字菜单和分科课程。幼儿这里的进度不原样搬进小学的数学或科学。
