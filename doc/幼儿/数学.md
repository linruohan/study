# 幼儿的数

这一档学的是数量和形状，用实物和手指，不写算式，也不叫「数学课」。

| 年龄 | 做得到的事 |
| --- | --- |
| 3 岁 | 口数 1–5，点一下数一个，指出哪边多 |
| 4 岁 | 数到 10，把说出的数量和实物对上，认识圆、方、三角 |
| 5 岁 | 5 以内说「拿走一个还剩几个」，按大小或颜色排三个东西，找到重复的规律，例如红蓝红蓝 |

画面是盘子、楼梯、积木和手指。数错时，带路的人再数一遍，并让已经数过的物体保持亮着。不出现倒计时和名次。

路径上的一步只做其中一件。点数技能同样走尝试、熟悉、熟练、掌握：换一批实物仍能点对，才进入下一个数。混在一起再点时若错过，就降一档。
