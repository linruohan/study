# 硕士三年：硕一连方法，硕二交成果，硕三接行业

总表见 [../分阶段学习方案.md](../分阶段学习方案.md)。这里按「每一年结束时拿得出什么」来组织。

## 硕一：把行业语言学会

- **拿得出**：一套本岗位的核心方法工具清单（每个都真实用过一次）；两个拆到可复用的行业案例。
- 怎么做：课程挑与目标岗位直接相关的；案例拆解记四行——它解决什么问题、用了什么办法、成败条件、我能迁移什么。
- 职业素养从第一天起就是课程的一部分：每次小组任务后写一段协作复盘。
- 对应九境：巩固**通境**——能把方法从一个情境搬到另一个情境。

## 硕二：在真实约束下交付

- **拿得出**：至少一段企业实践或项目实训的阶段交付物；一份能给人看的作品集初版。
- 怎么做：接真实任务，接受真实约束（成本、进度、质量）；每个阶段结束写复盘——计划了什么、发生了什么、下次改什么。
- 决策练习：凡有权衡的地方，写下「为什么选这个不选那个」，这是辨境的底子。
- 对应九境：走向**辨境**——能辨识问题里的关键约束，而不是套模板。

## 硕三：能独立负责一块

- **拿得出**：一份系统的毕业实践/专业学位论文；一段可讲的「我负责过什么」。
- 怎么做：总结按问题 → 方法 → 过程 → 结果四段写；复盘至少三轮，每轮留修改记录。
- 行业衔接：目标岗位的能力要求逐条对照自己的证据链，缺什么补什么。
- 对应九境：向**创境**起步——在交付里留下自己的方法或工具，就是知识增量。
- 之后：在职提升或转研究方向，按目标切换到 [../研究生/目录.md](../研究生/目录.md) 的研究标准。

## 不做的事

- 不以年限为里程碑：作品集和证据链够了就是够了。
- 不堆证书代替交付物：证书只算证据的一种，能拿出手的成果才算数。
- 不比较薪资与头衔：路径不同，标准不同。
