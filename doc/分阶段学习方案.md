# 分阶段学习方案

> 本方案已作为系统内置「学习计划方案」灌库（迁移 024，`plan_schemes` 等三张表）：
> 服务端 `/api/plan-schemes` 提供内置方案的读取与用户自建方案（空白创建/复制内置）的增删改。

本方案按学习阶段与年级划分学习目标、知识范围与能力程度，供课程设计、学习路径规划与项目文档对齐使用。

## 使用说明

- **阶段划分**：蒙学、小学（一至六年级）、初中（初一至初三）、高中（高一至高三）、大学（大一至大四）、研究生（研一至研三）、硕士（硕一至硕三）。
- **知识与学习程度**：每个阶段给出核心领域、典型知识内容与能力要求；同一领域在不同阶段强调不同深度，避免简单重复。
- **与现有文档关系**：本方案是总览性规划；各阶段细化内容可继续在 `doc/幼儿`、`doc/小学`、`doc/中学`、`doc/大学` 等目录中补充专题材料。
- **术语说明**：实践中“研究生”与“硕士研究生”常指同一学历层次；本方案按用户要求将“研究生（研一至研三）”与“硕士（硕一至硕三）”分别列为两套培养方案，便于按培养目标选用（如学术型研究生路径与专业型硕士路径）。

## 一、蒙学

**适用对象**：学前启蒙阶段（约 3–6 岁）  
**培养目标**：建立安全感与学习兴趣，发展语言、感知、动作、情绪与社会性基础，为小学学习做准备。

| 维度 | 知识内容 | 学习程度/能力表现 |
| --- | --- | --- |
| 语言与识字 | 听故事、儿歌、常用词汇；看图认字；简单口语表达 | 能听懂简单指令与故事大意；愿意表达；认识少量常见字词（不强求书写） |
| 数学启蒙 | 数数、比大小、认形状、简单分类与对应 | 能点数常见物品；辨别多少、长短、大小；认识基本图形 |
| 科学与探究 | 观察动植物、天气、水与影子等生活现象 | 对周围事物有好奇心；能用简单语言描述观察结果 |
| 艺术与审美 | 涂鸦、手工、音乐律动、欣赏图画 | 愿意参与创作与表现；能跟随节奏做简单动作 |
| 健康与运动 | 基本动作、卫生习惯、作息常规 | 能完成走跑跳等基础动作；养成洗手、整理等习惯 |
| 社会与情绪 | 规则意识、分享合作、情绪表达 | 能在引导下等待与轮流；初步识别并表达基本情绪 |

## 二、小学（一年级至六年级）

**培养目标**：掌握基础读写算能力，形成学习习惯与规则意识，初步建立自然、社会与审美认知框架。

### 1. 一年级
| 领域 | 知识内容 | 学习程度 |
| --- | --- | --- |
| 语文 | 拼音、基础汉字、简单词句、朗读与口语交际 | 能正确拼读；认识常用字并书写规范；能读通短句、表达完整意思 |
| 数学 | 20以内数与加减法、认识图形、简单比较与分类、认识钟表与人民币 | 能进行基础口算；辨认常见图形；理解简单数量关系 |
| 科学/常识 | 校园与家庭环境、动植物初步认识、季节与天气 | 能观察并描述身边现象；养成基本安全与卫生意识 |
| 艺术体育 | 音乐节奏、简单美术表现、基本体能活动 | 乐于参与；能完成简单动作与作品 |
| 品德与习惯 | 课堂规则、同伴交往、时间与物品管理 | 能遵守基本规则；在提醒下完成简单任务 |

### 2. 二年级
| 领域 | 知识内容 | 学习程度 |
| --- | --- | --- |
| 语文 | 常用汉字扩展、词语积累、短文阅读、看图写话/短句写作 | 阅读简单短文并回答问题；能写几句通顺的话 |
| 数学 | 100以内数与运算、表内乘除初步、长度与时间单位初步 | 口算与笔算更熟练；能解决一步简单应用题 |
| 科学/常识 | 生活材料、简单实验观察、动植物生长 | 能提出简单问题并参与观察活动 |
| 艺术体育 | 节奏与旋律感受、造型与色彩、跑跳投基础 | 动作协调性提高；能表达简单感受 |
| 品德与习惯 | 责任意识、合作完成任务 | 能独立完成部分学习与生活任务 |

### 3. 三年级
| 领域 | 知识内容 | 学习程度 |
| --- | --- | --- |
| 语文 | 段落阅读、概括主要内容、习作起步、口头表达 | 能理解段落大意；能写结构完整的短文 |
| 数学 | 万以内数、四则运算、周长面积初步、分数初步认识 | 能进行较复杂计算；理解基本图形与数量关系 |
| 科学 | 植物与动物特征、材料与运动、简单实验记录 | 能按步骤观察记录；形成初步证据意识 |
| 英语（如开设） | 字母、基础词汇与日常问候句型 | 能听懂并模仿简单表达 |
| 综合素养 | 信息获取初步、劳动与安全教育 | 能在指导下查找资料并完成简单实践任务 |

### 4. 四年级
| 领域 | 知识内容 | 学习程度 |
| --- | --- | --- |
| 语文 | 说明性与叙事性文本阅读、提取关键信息、习作条理化 | 能抓住要点复述；作文有较清晰结构 |
| 数学 | 大数认识、多位数运算、小数初步、图形与统计初步 | 能选择合适方法解题；能读懂简单图表 |
| 科学 | 电与磁初步、地球与空间初步、科学探究过程 | 能提出假设并做对比观察 |
| 英语 | 日常主题词汇、基础句型与短对话 | 能进行简单情境交流与阅读短句 |
| 综合素养 | 自主学习习惯、团队协作 | 能制定简单学习计划并执行 |

### 5. 五年级
| 领域 | 知识内容 | 学习程度 |
| --- | --- | --- |
| 语文 | 多种文体阅读、概括与简单推断、说明与记叙写作 | 能理解作者表达意图的表层线索；能围绕主题写作 |
| 数学 | 分数小数运算、体积与面积综合、简易方程、统计图表 | 能分析较复杂的数量关系；解决多步骤问题 |
| 科学 | 人体与健康、能量与运动、物质变化初步 | 能解释常见现象并联系生活 |
| 英语 | 阅读短文、基础写作与听说综合运用 | 能理解短文主旨并完成简单书面表达 |
| 综合素养 | 信息辨别初步、项目式学习体验 | 能合作完成主题探究并展示成果 |

### 6. 六年级
| 领域 | 知识内容 | 学习程度 |
| --- | --- | --- |
| 语文 | 阅读理解综合训练、表达与论述萌芽、写作完整性 | 能独立阅读并形成观点；写作逻辑较清楚 |
| 数学 | 比与比例、圆与百分数、综合应用问题、代数思维准备 | 能综合运用知识解决实际问题；为初中数学衔接 |
| 科学 | 系统梳理生命、物质、地球与技术主题 | 能进行较完整的探究与总结 |
| 英语 | 语篇阅读、基础语法综合、口头与书面表达 | 能在熟悉话题上进行较连贯表达 |
| 综合素养 | 自我管理、升学衔接准备 | 具备初步自主学习与复盘能力 |

## 三、初中（初一至初三）

**培养目标**：建立分科知识体系，发展逻辑思维、实验探究与表达论证能力，形成价值判断与社会责任意识。

### 1. 初一
| 领域 | 知识内容 | 学习程度 |
| --- | --- | --- |
| 语文 | 文言文入门、现代文阅读、写作结构训练 | 能理解常见文言词句；能写有中心、有条理的文章 |
| 数学 | 有理数、整式、一次方程、几何初步 | 掌握代数基本运算；建立空间与图形观念 |
| 英语 | 基础语法系统化、听说读写综合 | 能进行日常交流；阅读并理解简短语篇 |
| 科学/物理化学生物 | 科学方法、生命系统基础、物质与运动入门（按课程设置） | 能进行规范观察与简单实验 |
| 历史地理道德与法治 | 中国古代史与世界古代史基础、地图与区域认知、公民意识 | 能建立时空框架；理解基本社会规则 |

### 2. 初二
| 领域 | 知识内容 | 学习程度 |
| --- | --- | --- |
| 语文 | 文言文与现代文并进、议论与说明表达 | 能分析文本内容与写法；观点表达更清晰 |
| 数学 | 一次函数、全等与相似初步、实数与方程组 | 能用函数与方程建模简单问题 |
| 英语 | 复杂句型、阅读理解与书面表达提升 | 能理解中等难度文本并完成写作任务 |
| 物理/化学/生物 | 力学或物质基础、实验设计与数据分析 | 能解释现象背后的基本原理 |
| 历史地理道德与法治 | 近现代史脉络、自然与人文地理、法律常识 | 能进行因果分析与区域比较 |

### 3. 初三
| 领域 | 知识内容 | 学习程度 |
| --- | --- | --- |
| 语文 | 综合阅读、写作强化、古今文本联系 | 能进行较深入理解与规范表达 |
| 数学 | 二次函数、圆与概率统计基础、综合解题 | 能综合运用多知识点解决问题 |
| 英语 | 中考水平听说读写综合能力 | 能在熟悉与半熟悉语境中准确表达 |
| 物理/化学/生物 | 核心概念整合与实验能力提升 | 能进行规范实验分析与结论表述 |
| 历史地理道德与法治 | 知识体系整合、社会议题理解 | 能基于事实进行分析与价值判断 |

## 四、高中（高一至高三）

**培养目标**：深化学科理解与抽象思维，发展研究性学习、批判性思考与学业/生涯规划能力。

### 1. 高一
| 领域 | 知识内容 | 学习程度 |
| --- | --- | --- |
| 语文 | 文学作品鉴赏、论述类文本阅读、写作思辨性提升 | 能分析文本结构与观点；形成有依据的表达 |
| 数学 | 集合与函数、立体几何初步、解析几何入门、统计与概率 | 理解抽象概念并进行基本证明与建模 |
| 英语 | 语篇理解、应用写作、口语表达 | 能处理较长文本并进行清晰表达 |
| 物理/化学/生物 | 运动与力、物质结构与反应、细胞与遗传基础 | 建立学科核心概念，能进行定量与定性分析 |
| 历史/地理/政治 | 中外历史专题、自然与人文地理规律、经济政治思想基础 | 能从多角度解释历史与现实问题 |
| 通用能力 | 学习策略、信息检索、实验与探究规范 | 形成自主学习与初步研究意识 |

### 2. 高二
| 领域 | 知识内容 | 学习程度 |
| --- | --- | --- |
| 语文 | 文化经典阅读、复杂论证写作 | 能进行文本比较与深度分析 |
| 数学 | 导数初步、数列、概率统计深化、综合问题 | 能进行较复杂推理与模型应用 |
| 英语 | 学术性阅读与表达初步 | 能围绕主题进行论述与交流 |
| 选考/主修学科 | 在物化生史地政等方向上深化模块学习 | 形成学科优势与知识网络 |
| 研究与实践 | 课题研究、实验报告、社会实践 | 能提出问题、收集证据并形成结论 |

### 3. 高三
| 领域 | 知识内容 | 学习程度 |
| --- | --- | --- |
| 语文 | 综合阅读与写作能力整合 | 能稳定输出高质量理解与表达 |
| 数学 | 知识体系整合与综合应用 | 能灵活迁移方法解决新问题 |
| 英语 | 综合语言运用能力巩固 | 能准确、得体地完成复杂任务 |
| 选考/主修学科 | 核心考点与能力要求整合 | 达到阶段性学业评价要求 |
| 生涯规划 | 专业选择、升学准备、自我认知 | 能结合兴趣与能力做出理性规划 |

## 五、大学（大一至大四）

**培养目标**：完成通识与专业基础教育，发展专业能力、批判性思维、协作创新与终身学习能力。

### 1. 大一
| 领域 | 知识内容 | 学习程度 |
| --- | --- | --- |
| 通识教育 | 大学写作、数学/逻辑基础、信息素养、外语或跨文化交流 | 适应大学学习方式；具备基本学术表达与检索能力 |
| 专业导论 | 学科概貌、核心概念、基本方法 | 了解专业图景与发展方向 |
| 实践能力 | 基础实验/实训/项目体验 | 能在指导下完成基础任务 |
| 自我发展 | 时间管理、学习规划、团队合作 | 建立自主学习与自我管理习惯 |

### 2. 大二
| 领域 | 知识内容 | 学习程度 |
| --- | --- | --- |
| 专业基础课 | 学科核心理论、方法与工具课程 | 掌握专业基础知识并能解决典型问题 |
| 通识拓展 | 跨学科选修、人文社科或科学素养课程 | 形成更宽广的知识视角 |
| 方法训练 | 文献阅读、数据处理/实验技能/案例分析 | 能规范地获取与处理信息 |
| 项目实践 | 课程设计、小组项目 | 能在团队中承担明确角色并交付成果 |

### 3. 大三
| 领域 | 知识内容 | 学习程度 |
| --- | --- | --- |
| 专业核心课 | 方向性核心课程、专题课程 | 深入理解专业关键问题与前沿基础 |
| 研究/工程能力 | 研究方法、工程规范、创新实践 | 能独立完成中等复杂度任务 |
| 实习实训 | 企业/机构实践或科研训练 | 将理论应用于真实场景，积累经验 |
| 职业/升学准备 | 作品集、实习总结、考研/就业规划 | 明确发展路径并积累支撑材料 |

### 4. 大四
| 领域 | 知识内容 | 学习程度 |
| --- | --- | --- |
| 综合训练 | 毕业设计/毕业论文/综合实践 | 能围绕真实问题完成系统性成果 |
| 专业整合 | 知识融会贯通、跨课程综合应用 | 形成完整的专业能力结构 |
| 职业能力 | 沟通表达、项目管理、职业伦理 | 达到初入职场或继续深造的准备度 |
| 总结反思 | 学习复盘、能力评估、长期规划 | 能清晰表述自身能力与发展方向 |

## 六、研究生（研一至研三）

> 本方案侧重**学术研究能力培养**（可对应学术型研究生路径）。

**培养目标**：掌握领域前沿知识与研究方法，具备独立开展研究、产出学术成果的能力。

### 1. 研一
| 领域 | 知识内容 | 学习程度 |
| --- | --- | --- |
| 理论基础 | 高阶专业课程、研究领域核心文献 | 系统掌握本方向理论框架与关键问题 |
| 研究方法 | 研究设计、文献综述、学术规范与伦理 | 能检索、阅读并评述文献；理解研究范式 |
| 学术训练 | 研讨课、论文研读、实验/调研技能 | 能参与学术讨论并提出有价值问题 |
| 选题准备 | 确定研究兴趣与初步方向 | 形成可行的研究问题雏形 |

### 2. 研二
| 领域 | 知识内容 | 学习程度 |
| --- | --- | --- |
| 专题研究 | 围绕选题的深入文献与理论/技术攻关 | 对研究问题具备较全面把握 |
| 研究实施 | 实验、数据采集、建模、案例或田野工作 | 能独立推进研究环节并处理常见问题 |
| 学术产出 | 论文写作、会议交流、阶段性成果 | 能形成规范的研究报告或论文初稿 |
| 协作与交流 | 参与课题组、学术汇报与同行反馈 | 能回应质疑并改进研究设计 |

### 3. 研三
| 领域 | 知识内容 | 学习程度 |
| --- | --- | --- |
| 成果凝练 | 学位论文撰写、研究结论提炼 | 能形成逻辑严密、证据充分的学术成果 |
| 创新贡献 | 对领域问题提出新理解、方法或应用证据 | 在限定范围内体现创新性与严谨性 |
| 答辩与发表 | 论文答辩、投稿修改、成果展示 | 能清晰阐述研究价值与局限 |
| 发展规划 | 博士深造/学术岗位/研发岗位准备 | 明确后续学术或职业发展方向 |

## 七、硕士（硕一至硕三）

> 本方案侧重**专业实践与应用能力培养**（可对应专业型硕士路径）。

**培养目标**：强化专业理论与行业实践结合，提升复杂问题解决、项目交付与职业发展能力。

### 1. 硕一
| 领域 | 知识内容 | 学习程度 |
| --- | --- | --- |
| 专业核心课 | 面向实践的高阶课程、行业知识框架 | 掌握岗位相关核心知识与工具 |
| 方法与工具 | 数据分析/设计/管理/工程方法等（依专业而定） | 能运用专业方法分析实际问题 |
| 案例学习 | 行业案例、最佳实践、标准规范 | 能从案例中抽象可迁移经验 |
| 职业素养 | 团队协作、沟通表达、职业伦理 | 适应专业场景的协作与沟通要求 |

### 2. 硕二
| 领域 | 知识内容 | 学习程度 |
| --- | --- | --- |
| 专业深化 | 方向选修、前沿应用专题 | 在细分方向形成较强应用能力 |
| 实践训练 | 企业实践、项目实训、实验/设计/咨询任务 | 能在真实约束下推进项目并交付阶段成果 |
| 综合能力 | 需求分析、方案设计、风险与质量意识 | 能权衡成本、进度与质量做出决策 |
| 成果准备 | 实践报告、项目文档、作品集积累 | 形成可展示的专业成果 |

### 3. 硕三
| 领域 | 知识内容 | 学习程度 |
| --- | --- | --- |
| 毕业实践/论文 | 应用研究、工程项目总结或专业学位论文 | 能系统总结问题、方法、过程与结果 |
| 职业交付能力 | 方案落地、复盘优化、跨角色沟通 | 具备独立负责模块或项目的能力 |
| 行业衔接 | 求职/岗位胜任/创业或在职提升准备 | 达到目标岗位的专业与综合能力要求 |
| 持续成长 | 终身学习计划、专业网络与发展路径 | 能规划持续提升方向与学习资源 |

## 附：阶段衔接要点

| 衔接节点 | 关注重点 |
| --- | --- |
| 蒙学 → 小学 | 从游戏化、口语化体验过渡到规范读写算与课堂习惯 |
| 小学 → 初中 | 从具体经验学习过渡到分科概念与抽象思维 |
| 初中 → 高中 | 从基础知识掌握过渡到原理理解、论证与选择性发展 |
| 高中 → 大学 | 从统一课程过渡到专业选择、自主学习与学术/职业准备 |
| 大学 → 研究生/硕士 | 从知识接受与应用过渡到研究创新或高阶专业实践 |
| 研究生 ↔ 硕士路径 | 按目标选择学术研究导向或专业实践导向，避免混用培养标准 |
